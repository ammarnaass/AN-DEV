# توثيق تدفق تجربة المستخدم وهندسة التنقل (User Flow Architecture)
## مشروع منصة AN DEV البرمجية — الإصدار 1.0 (v1.0)
**الهوية:** Code · Create · Solve  
**المقر:** الجزائر العاصمة (Algiers, DZ)  
**المعمارية التقنية:** React 19 + TypeScript + Vite + Fastify + SQLite WAL + Drizzle ORM + Litestream  
**نظام التصميم:** Cybernetic Precision (Dark Mode / High-Contrast Tech Blueprint)

---

## 1. نظرة عامة على هيكلية النظام (System Architecture Overview)

تتألف منصة **AN DEV** من بيئتين تشغيليتين متكاملتين:
1. **الواجهة العامة للمستخدم والعميل (Public Portal):** موجهة للعملاء، مهندسي البرمجيات، والشركات المهتمة بالحلول التقنية والأنظمة الموزعة.
2. **بوابة الإدارة المركزية (Admin Control Plane):** لوحة تحكم مغلقة ومؤمنة للمشرف العام والمهندسين لإدارة المشاريع، الطلبات، ومعايير النظام وقواعد البيانات.

## 3. مسار رحلة الزائر والعميل (Public Customer Journey)

### 3.1 الصفحة الرئيسية (`/`)
* **الهدف:** بناء الانطباع التقني الأولي، استعراض فلسفة الأداء العالي، وإبراز القدرات البرمجية.
* **نقاط التفاعل والتوجيه:**
  * **زر الإجراء السريع (Hero CTA):** ينقل العميل إلى صفحة `طلب مشروع وتواصل (/contact)`.
  * **قسم المشاريع المميزة:** معاينة بطاقات تفاعلية تنقل مباشرة إلى `معرض الأعمال (/projects)` أو إلى صفحة المشروع المحددة.
  * **شريط التنقل العلوي (App Shell Navigation):** روابط سلسة للرئيسية، الأعمال، المدونة، والتواصل، مع محول اللغة والوضع الليلي.

### 3.2 معرض الأعمال (`/projects`)
* **الهدف:** استعراض مكتبة المنظومات المنفذة مع نظام تصفية فوري حسب الفئة (Fintech, SaaS, Enterprise, Mobile).
* **إجراءات المستخدم:**
  * تصفية وفلترة المشاريع التقنية.
  * النقر على بطاقة مشروع ينقل الزائر إلى صفحة `تفاصيل المشروع (/projects/:slug)`.

### 3.3 دراسة حالة وتفاصيل المشروع (`/projects/:slug`)
* **الهدف:** تقديم دراسة هندسية مفصلة (Case Study) تبرز الأثر التشغيلي، المعمارية البرمجية، وقياسات الأداء (Benchmarks).
* **المكونات التفاعلية:**
  * معاينة لوحة تحكم حية للمشروع داخل إطار تفاعلي.
  * تفكيك التحدي المعماري وخطوات الحل مع كود مصدري حقيقي.
  * التحقق من التوافقية مع بوابات الدفع الوطنية الجزائرية (Satim / CIB / Edahabia).
  * **زر التحويل (Conversion CTA):** زر "ابدأ مشروعك الآن" ينقل العميل مباشرة لصفحة `طلب مشروع وتواصل (/contact)`.

### 3.4 طلب مشروع واستشارة (`/contact`)
* **الهدف:** التقاط متطلبات العملاء المؤهلين عبر نموذج تقني مفصل (Scope, Budget, Timelines, Stack).
* **التدفق الخلفي:**
  * التحقق من المدخلات عبر Zod Schemas وحماية خفية ضد البوتات (Honeypot).
  * حفظ الطلب آلياً في قاعدة بيانات SQLite WAL.
  * إشعار لوحة الإدارة فورياً وظهور الطلب في صفحة `إدارة الطلبات (/admin/inquiries)`.

### 3.5 المدونة الهندسية وتفاصيل المقالات (`/blog` & `/blog/:slug`)
* **الهدف:** تعزيز سلطة العلامة التقنية (Thought Leadership) من خلال نشر دراسات معمقة حول Fastify, SQLite WAL, والمصغرات السحابية.
* **المكونات:**
  * فلاتر التصنيف وشريط البحث الفوري (⌘ K).
  * بطاقة المقال المميز (Featured Post).
  * صفحة المقال الفردي مع فهرس محتويات مثبت (Sticky TOC) يتابع القراءة لحظياً، مع زر طلب تدقيق معماري.

### 3.6 معالجة المسارات المفقودة (`/404`)
* **الهدف:** توجيه المستخدم التائه أو رابط خاطئ والحد من معدل الارتداد (Bounce Rate).
* **العناصر:**
  * نافذة تشخيص سريعة تشبه الطرفية (Debug Console).
  * حقل بحث مباشر ومصفوفة روابط سريعة للرئيسية، معرض الأعمال، والمدونة.

## 4. مسار رحلة الإدارة والتحكم (Admin Operations Journey)

### 4.1 بوابة الدخول والمصادقة (`/admin/login`)
* **الهدف:** عزل لوحة الإدارة بحماية مشددة (Zero-Trust Gateway).
* **معايير الأمان:**
  * تشفير Argon2id لكلمات المرور.
  * التحقق الثنائي الإلزامي (TOTP / YubiKey).
  * تحديد معدل المحاولات (Rate Limiting: 5 محاولات كحد أقصى).
  * كوكيز آمنة (`HttpOnly; Secure; SameSite=Lax`).
  * عند نجاح المصادقة: إعادة التوجيه إلى `لوحة التحكم الرئيسية (/admin)`.

### 4.2 لوحة التحكم الرئيسية (`/admin`)
* **الهدف:** المراقبة الحية للحالة التشغيلية ومؤشرات الأداء.
* **المؤشرات الحية:**
  * مقاييس استجابة الخوادم (Fastify Engine Latency).
  * حالة محرك البيانات (SQLite WAL + Litestream Backup).
  * عداد الطلبات الجديدة المعلقة التي تحتاج لمراجعة.
  * شريط جانبي دائم (Persistent Sidebar) يتيح التنقل السلس بين أقسام الإدارة وزيارة الموقع العام.

### 4.3 إدارة طلبات المشاريع (`/admin/inquiries`)
* **الهدف:** معالجة واستقبال الاستشارات والطلبات المحقونة من صفحة التواصل.
* **إجراءات المشرف:**
  * فرز وتصفية الطلبات (جديد، قيد المتابعة، تم الاعتماد، مؤرشف).
  * معاينة الميزانية المقترحة، نطاق العمل، والمواصفات الفنية.
  * كتابة ملاحظات إدارية وتحديث حالة المعالجة.

### 4.4 إدارة المشاريع والمعرض (`/admin/projects`)
* **الهدف:** التحكم الكامل في معرض الأعمال والبيانات المعروضة للجمهور.
* **إجراءات المشرف:**
  * إضافة مشاريع جديدة وتحديد الوسوم والتقنيات المستخدمة.
  * ترتيب ظهور المشاريع بالسحب والإفلات وتعيين المشاريع المميزة للواجهة الرئيسية.
  * رفع الأصول البصرية ومعالجتها تلقائياً بصيغة WebP.

### 4.5 إعدادات الموقع والنظام (`/admin/settings`)
* **الهدف:** ضبط المتغيرات المركزية للنظام والموقع العام.
* **الأقسام الخمسة:**
  1. **بيانات التواصل والمقر:** تحديث هاتف المكتب، البريد الرسمي، والعنوان في الجزائر العاصمة.
  2. **روابط المجتمعات:** إدارة منصات GitHub, LinkedIn, Telegram وفحص استجابتها برمجياً.
  3. **محركات البحث وSEO:** إدارة Meta Tags، وصف الموقع، ومزامنة sitemap.xml.
  4. **جلسات الأمان:** ضبط صلاحية الجلسات وحماية الـ Honeypot.
  5. **قاعدة البيانات والنسخ الاحتياطي:** أخذ لقطة فورية (Snapshot Now) ومراقبة مزامنة Litestream S3.
