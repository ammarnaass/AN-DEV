# PRD موقع AN DEV
الإصدار 1.0 · الشعار: Code · Create · Solve · المعمارية: Vite + Fastify + SQLite

## 1. نظرة عامة
موقع AN DEV هو الواجهة الرقمية لشركة برمجيات (الجزائر) تبني تطبيقات ويب وموبايل وأنظمة مخصصة. الموقع يعرض الخدمات والأعمال، ويستقبل طلبات المشاريع، ويُدار من لوحة تحكم بسيطة دون تعديل الكود.
المشكلة: الموقع الحالي صفحة ثابتة، فلا توجد طريقة لاستقبال الطلبات أو تحديث الأعمال أو قياس الزيارات.
الحل: تطبيق ويب بواجهة React عبر Vite، وخادم API خفيف مع قاعدة بيانات SQLite، ولوحة إدارة محمية.

## 2. الأهداف ومقاييس النجاح
- جذب عملاء: طلبات مشاريع شهرياً من النموذج 10 أو أكثر بعد 3 أشهر.
- بناء الثقة: عدد المشاريع المنشورة في معرض الأعمال 6 عند الإطلاق.
- سرعة: Lighthouse Performance على الموبايل 90 أو أكثر.
- سهولة الإدارة: تحديث محتوى دون مبرمج في أقل من 5 دقائق.

## 3. المستخدمون
- الزائر / العميل المحتمل: صاحب نشاط يبحث عن مطوّر. يريد فهم الخدمات بسرعة ورؤية أعمال سابقة والتواصل بسهولة.
- المدير (Ammar): يضيف المشاريع، ويقرأ الطلبات ويتابع حالتها، ويعدّل نصوص الموقع.

## 4. النطاق
داخل النطاق:
- موقع عام بالعربية (RTL) مع إنجليزية كلغة ثانية.
- معرض أعمال، وخدمات، ونموذج طلب مشروع.
- لوحة إدارة: مشاريع، طلبات، إعدادات، مقالات.
- مدونة قصيرة (Markdown) لدعم الظهور في البحث.
خارج النطاق حالياً: بوابة دفع، حسابات للعملاء، دردشة مباشرة، تطبيق موبايل.

## 5. المتطلبات الوظيفية
- F1: صفحة رئيسية: واجهة، خدمات، تقنيات، مراحل العمل، تواصل (P0)
- F2: معرض أعمال مع صفحة تفاصيل لكل مشروع (وصف، تقنيات، صور، رابط) (P0)
- F3: نموذج طلب مشروع (الاسم، البريد، نوع المشروع، الميزانية، الوصف) (P0)
- F4: حفظ الطلبات في SQLite وإرسال إشعار بريد للمدير (P0)
- F5: تسجيل دخول المدير (جلسة آمنة) (P0)
- F6: إدارة المشاريع: إضافة، تعديل، حذف، إخفاء، رفع صور (P0)
- F7: إدارة الطلبات: قائمة، فلترة بالحالة (جديد، قيد المتابعة، مغلق)، ملاحظات (P1)
- F8: تبديل اللغة عربي / إنجليزي (P1)
- F9: مدونة: مقالات Markdown مع تصنيفات (P2)
- F10: إحصاءات زيارات بسيطة بلا كوكيز (عدّاد صفحات في SQLite) (P2)
- F11: وسوم SEO وOpen Graph وخريطة موقع sitemap.xml (P1)

## 6. المتطلبات غير الوظيفية
- الأداء: تحميل أول أقل من 2 ثانية على 4G، وصور WebP، وتقسيم الكود.
- الأمان: تشفير كلمات المرور بـ argon2، وحماية CSRF، وتحديد معدل الطلبات، وتنقية المدخلات (zod)، وHTTPS إجباري.
- الوصول: تباين ألوان كافٍ (4.5:1 على الأقل)، وتنقل بلوحة المفاتيح، وتقليل الحركة مع prefers-reduced-motion.
- التوافق: أحدث نسختين من Chrome وFirefox وSafari وEdge، وتصميم متجاوب من 360px.
- الصيانة: TypeScript في كل المشروع، واختبارات للمسارات الحرجة.

## 7. هوية التصميم
- الألوان:
  - `--bg`: #050816 (Dark) / #F4F7FD (Light)
  - `--surface`: #0B1430 (Dark) / #FFFFFF (Light)
  - `--line`: #1A2850 (Dark) / #C9D6F2 (Light)
  - `--ink`: #E6E6E6 (Dark) / #0B1226 (Light)
  - `--mute`: #8D99B3 (Dark) / #4B5878 (Light)
  - `--primary`: #0D6EFD
  - `--accent`: #00C3FF (Dark) / #0087B8 (Light)
- الخطوط: Cairo للعربية، Poppins للعناوين وInter للنصوص للإنجليزية. monospace للأكواد.
- زوايا الأزرار والحقول 10px، البطاقات 14px، الوسوم 999px.

## 8. خريطة الصفحات
- `/`: الرئيسية
- `/projects`: معرض الأعمال
- `/projects/:slug`: تفاصيل مشروع
- `/blog`, `/blog/:slug`: المدونة
- `/contact`: طلب مشروع
- `/admin/login`: دخول المدير
- `/admin`: لوحة التحكم (مشاريع، طلبات، مقالات، إعدادات)

## 9. نموذج البيانات (SQLite / Drizzle)
- `projects`: id, slug, title_ar, title_en, summary_ar, summary_en, body_ar, body_en, tech_json, cover_image, live_url, repo_url, featured, published, sort_order, created_at, updated_at
- `project_images`: id, project_id, path, alt_ar, alt_en, sort_order
- `inquiries`: id, name, email, project_type, budget_range, message, status (new, in_progress, closed), admin_note, ip_hash, created_at
- `posts`: id, slug, title_ar, title_en, body_md_ar, body_md_en, published, published_at
- `admins`: id, email, password_hash, created_at
- `sessions`: id, admin_id, expires_at
- `settings`: key (PK), value
- `page_views`: id, path, day, count
